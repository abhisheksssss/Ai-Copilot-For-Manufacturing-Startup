# Overview

India’s first Variable Speed Pumped Storage Plant is a 1,000 MW hydropower project executed by THDC India Limited (THDCIL), under the Ministry of Power. The technology partner for this project is GE Vernova, which provided power electronics and a 250 MW variable-speed unit.

# Benefits

- **First Variable-Speed PSP in India**: This marks a significant leap in hydropower innovation.
- **Enhanced Efficiency**: Variable-speed turbines allow precise control over pumping and generation, improving overall system efficiency.
- **Improved Grid Stability**: The plant enables real-time power adjustments, supporting grid stability amid renewable energy fluctuations.
- **Flexible Operation**: It can swiftly switch between pumping and generation to adapt to dynamic grid demands.
- **Energy Storage**: Functions like a giant water battery, storing surplus energy for peak-hour power generation.
