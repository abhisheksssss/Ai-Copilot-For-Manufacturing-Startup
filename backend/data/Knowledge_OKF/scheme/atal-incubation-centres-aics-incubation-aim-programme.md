# Overview
The Atal Incubation Centres (AICs) Incubation AIM Programme supports world-class incubators across universities, institutions, and private hosts to foster a robust startup ecosystem.

# Eligibility
Host institutions/incubators; startups benefit through incubation services.

# Benefits
Startups receive incubation services, mentoring, and networking opportunities.

# Funding
Up to ₹10 crore per incubator, subject to guidelines set by the Atal Innovation Mission (AIM), NITI Aayog.
