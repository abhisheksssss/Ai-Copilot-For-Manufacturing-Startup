# Overview
Bharat Taxi is a national ride-hailing platform operated by Sahakar Taxi Cooperative Ltd., envisioned as India’s first cooperative-based alternative to global cab aggregators.

# Eligibility
Eligibility criteria are not explicitly mentioned in the provided text. However, it can be inferred that drivers and users must comply with the platform's terms of service and adhere to cybersecurity and compliance standards.

# Benefits
- Transparent and inclusive mobility services.
- Fair income for drivers.
- Secure and seamless user experience.
- Unified access through DigiLocker, UMANG, and API Setu for digital identity and document verification.
- Adherence to GoI’s data protection and privacy standards.
- Multilingual accessibility and an inclusive interface.
